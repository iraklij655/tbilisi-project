# თბილისი — აღმოაჩინე ქალაქი
სასწავლო Front-end პროექტი. პროექტი აერთიანებს დაგეგმვას, სემანტიკურ HTML5-ს, responsive CSS3-ს, JavaScript ინტერაქციას, Git სამუშაო პროცესს და ანგარიშგებას.
GitHub: https://github.com/iraklij655/tbilisi-project/tree/main/tbilisi_complete_project
## 1. პროექტის მიზანი
შეიქმნას ქართულენოვანი, მარტივად გამოსაყენებელი გზამკვლევი თბილისის ადგილების, მოკლე მარშრუტისა და პრაქტიკული რჩევების შესახებ.

## 2. ტექნოლოგიები და რესურსები
- HTML5: სემანტიკური სტრუქტურა, ფორმის label-ები, აღწერითი სათაურები.
- CSS3: Grid, Flexbox, media queries, focus states და reduced-motion.
- JavaScript: responsive მენიუ, Escape-ით დახურვა, სლაიდერი (წინა/შემდეგი, ინდიკატორები, ავტომატური გადართვა, პაუზა), ფორმის ვალიდაცია.
- Git/GitHub: ცვლილებების ეტაპობრივი commit-ები.
- რესურსები: კომპიუტერი, თანამედროვე ბრაუზერი, ტექსტური რედაქტორი და ინტერნეტი (Google Fonts-ისთვის).

## 4. რისკები და შემცირების გზები
- მობილურზე ელემენტების გადავსება — ტესტირება 375px, 768px და 1440px სიგანეებზე.
- ფორმის არასწორი მონაცემები — ცარიელი ველისა და არასწორი ელფოსტის ტესტირება.
- კლავიატურის გამოყენების სირთულე — focus-visible, skip link, Escape მენიუს დასახურად.
- ბრაუზერის შეცდომები — DevTools Console-ის შემოწმება და ძირითადი ბრაუზერების ტესტი.
- გარე ფონტის მიუწვდომლობა — სისტემური fallback ფონტები.

## 6. გაშვება
1. გახსენით `index.html` ბრაუზერში ან გამოიყენეთ VS Code Live Server.
2. პროექტი არ საჭიროებს build-ს ან პაკეტების ინსტალაციას.
3. Google Fonts-ისთვის საჭიროა ინტერნეტი; დანარჩენი ფუნქციონალი ლოკალურად მუშაობს.

## 7. ფუნქციონალის აღწერა
- ნავიგაციის ბმულები გადადის შესაბამის სექციებზე.
- სლაიდერი: ღილაკები ←/→, წერტილოვანი ინდიკატორები, ავტომატური გადართვა 5 წამში, პაუზა/გაგრძელება; `prefers-reduced-motion`-ის შემთხვევაში ავტომატური გადართვა გამორთულია.
- მობილური მენიუ იხსნება/იხურება ღილაკით, ბმულზე გადასვლისას და Escape-ით.
- ფორმა ამოწმებს სახელსა და ელფოსტას, აჩვენებს შეცდომას ან წარმატების შეტყობინებას.
- ფორმა სასწავლო დემოა: მონაცემები სერვერზე არ იგზავნება და არ ინახება.

## 9. Git/GitHub სამუშაო პროცესი
პროექტი ატვირთულია GitHub-ზე ეტაპობრივი, ლოგიკური commit-ებით:
```bash
git add index.html
git commit -m "Create semantic page structure"
git add css/style.css
git commit -m "Add responsive layout and visual styles"
git add js/main.js
git commit -m "Implement mobile navigation and form validation"
git commit -am "Add image slider with controls and autoplay"
git add README.md presentation.md
git commit -m "Document project and prepare presentation"
git push -u origin main
```

## 10. ოპტიმიზაცია
- არ გამოიყენება მძიმე JavaScript ბიბლიოთეკები ან framework-ები.
- CSS დეკორაციები შექმნილია CSS-ით და არ საჭიროებს დიდ ფოტო-ფაილებს.
- JavaScript ფაილი იტვირთება `defer`-ით.
- CSS ფაილი გაფორმატებულია და დაყოფილია კომენტარებით/ბლოკებით, რაც აადვილებს მხარდაჭერას.
- სექციები და კლასები თანმიმდევრულადაა დასახელებული.
- `prefers-reduced-motion` ითვალისწინებს მოძრაობის შემცირების სისტემურ პარამეტრს.

## 11. შეზღუდვები და სამომავლო გაუმჯობესება
ეს არის ფრონტენდის სასწავლო დემო. ფორმის რეალური გაგზავნისთვის საჭიროა backend ან ფორმის სერვისი. შემდეგ შეიძლება დაემატოს რეალური ფოტომასალა, რუკა, ფილტრი და დამატებითი მარშრუტები.
