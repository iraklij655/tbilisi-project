# პრეზენტაცია — თბილისი: აღმოაჩინე ქალაქი

## სლაიდი 1 — პროექტის სათაური
**თბილისი — აღმოაჩინე ქალაქი**  
Front-end პროგრამირება · პრაქტიკული პროექტი

## სლაიდი 2 — იდეა და მიზანი
- ქართულენოვანი მოკლე გზამკვლევი თბილისის სტუმრებისთვის
- ადგილები, ნახევარდღიანი მარშრუტი და პრაქტიკული რჩევები
- მკაფიო სტრუქტურა და responsive გამოცდილება

## სლაიდი 3 — დაგეგმვა
- მოთხოვნების გაანალიზება და გვერდის სექციების განსაზღვრა
- სამუშაო ეტაპები: დაგეგმვა → HTML → CSS → JavaScript → ტესტირება/ანგარიში
- რისკები: მცირე ეკრანის განლაგება, ფორმის მონაცემები, კლავიატურის ხელმისაწვდომობა

## სლაიდი 4 — ტექნოლოგიები
- HTML5: header, nav, main, section, article, footer, form
- CSS3: Grid, Flexbox, media queries, focus styles
- JavaScript: mobile navigation, image slider, Escape handling, form validation
- Git/GitHub: ეტაპობრივი commits

## სლაიდი 5 — გვერდის არქიტექტურა
- Hero და შესავალი
- ქალაქის ხედების სლაიდერი
- ღირსშესანიშნაობების ბარათები
- ნახევარდღიანი მარშრუტი
- მოგზაურობის რჩევები
- გზამკვლევის ფორმა და footer

## სლაიდი 6 — ინტერაქცია
- მობილური მენიუს გახსნა/დახურვა
- სლაიდერი: ←/→, ინდიკატორები, ავტომატური გადართვა, პაუზა
- კლავიატურით Escape-ის მხარდაჭერა
- ფორმის ვალიდაცია და status შეტყობინება
- დემო ფორმა მონაცემებს არ აგზავნის

## სლაიდი 7 — ტესტირება და ოპტიმიზაცია
- 375px, 768px და 1440px viewport-ები
- ცარიელი, არასწორი და სწორი ფორმის მონაცემები
- focus indicator, skip link, reduced-motion
- მსუბუქი პროექტი, გარე ბიბლიოთეკების გარეშე

## სლაიდი 8 — დასკვნა
პროექტი აჩვენებს დაგეგმვის, პროგრამული შესრულების, კოდის ტესტირებისა და ანგარიშგების ეტაპებს. შემდგომი ნაბიჯია backend ფორმის, რუკისა და რეალური ფოტოების დამატება.
